# Example

Illustrative shapes only, not a real run.

## Input

```
forge ideas --region=ID --lang=id --constraints="solo founder, under $5k, ship in 60 days": tools for small online sellers
```

## What happens

1. Framing: region Indonesia, language Indonesian, constraints captured. Sources steered to local communities plus global English.
2. Swarm: 5 personas search in Bahasa and English for repeated seller complaints (marketplace fees, returns, bookkeeping, shipping). Each returns ideas in schema with cited sources or a SPECULATIVE tag.
3. Verification: every cited URL is fetched. Two ideas citing dead links drop to SPECULATIVE.
4. Council: 5 critics score each idea on demand, problem-realness, buildability, survivability, clarity. Anonymous peer review. Chairman ranks.
5. Output: shortlist in chat, full HTML report, transcript, kill log appended.

## Shortlist shape (chat output)

```
1. Auto-reconciliation for marketplace payouts        8.4   EVIDENCED
   Sellers lose hours matching payouts to orders; no cheap local tool.
   First step: build the COD-payout parser for the top local marketplace.

2. Returns-reason analytics for small sellers          7.1   EVIDENCED
   Returns are frequent but sellers cannot see why; fixable with a light dashboard.
   First step: ingest one seller's 90 days of returns, cluster the reasons.

3. Localized chat-macro library for seller support      6.2   SPECULATIVE
   Plausible demand, weaker direct evidence; validate with 5 seller interviews first.
   First step: 5 interviews before any build.
```

Full rationale, risks, score breakdowns, the swarm dump, and the kill log live in the HTML report.
