# Source Map

Where each ideation persona looks for real problems, by region. The orchestrator selects rows by the detected or configured region. When region is unknown, use the Global / English row. Always allow web search in addition to these; this list steers it, it does not limit it.

Do not treat any single platform as authoritative. The goal is real, repeated complaints, wherever they live.

## Global / English (default)

- Reddit (topic-relevant subreddits), X / Twitter, Hacker News, Product Hunt comments
- Stack Exchange network, GitHub issues, app-store and Play-store reviews
- Industry-specific forums and Discord/Slack community recaps that are publicly indexed
- Trade press and newsletters in the domain

## Region steering (add to, do not replace, the global row)

- US / UK / CA / AU / global tech: the global row already fits.
- India (IN): regional subreddits, local startup press, vernacular-language X, Play-store reviews in-locale.
- Indonesia (ID) / SEA: Kaskus and local forums, regional subreddits, X in Bahasa, Tokopedia/Shopee review sections, local tech press.
- Brazil (BR) / LATAM: Reclame Aqui (complaint platform), regional subreddits, X in Portuguese/Spanish, local marketplace reviews.
- Germany / DACH (DE): regional forums, Trustpilot/local review sites, X in German, trade press in-language.
- Japan (JP): local Q&A and review sites, X in Japanese, app-store reviews in-locale.
- China-facing diaspora markets: publicly accessible forums and review aggregators in-language where available.

## Rules

- Search in the local language first, then English, when the region is non-English.
- Quote or summarize complaints faithfully; never translate in a way that changes the complaint.
- Prefer recent posts. Note the date of each cited source.
- If a region's best sources are not publicly accessible, fall back to global sources and flag the evidence as weaker.
